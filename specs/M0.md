# M0 — Research, reverse engineering, feasibility, and architecture

## Objective

Establish verified Galaxy 1 and toolchain facts, compare the supplied reference executables, select a revision, and define an evidence-led Rust-first architecture before runtime hooks are attempted.

## Verified research

- Local original and AllReds executables are present under `reference/`; their hashes match the values recorded in the master prompt (see `docs/references/dol-diff.md`).
- The upstream Galaxy Patch project documents a main.dol patch for all four regional IDs and describes synthesizing Classic Controller state in the KPAD sample buffer. This is a separate controller project and does not establish four-slot compatibility.
- Dolphin documents Wii NetPlay as experimental and lockstep: peers must maintain matching emulated state. This makes deterministic input simulation a plausible baseline, but does not synchronize arbitrary custom actors by itself.
- Petari is an in-progress SMG1 decompilation. Its progress, buildability, and symbol coverage must be checked at a pinned commit before taking dependencies.
- See `docs/research.md` and focused references for sources and limitations.

## Functional requirements

- Reproduce DOL hashes, section tables, shared-range changed byte count, changed runs, and entry point without modifying either executable.
- Compare the original against AllReds and distinguish facts from hypotheses.
- Document Rust host tooling and injected-runtime feasibility separately.
- Define network, controller, rendering, and player boundaries without fabricating game APIs.

## Technical design

Use a Cargo workspace. `multigalaxy-patch` owns safe DOL parsing/comparison primitives and synthetic tests; `multigalaxy` is its CLI. Later crates hold portable deterministic player/input/character logic. Wii-specific calls remain behind narrow reviewed FFI and verified assembly hooks. `no_std` is conditional on proven target/toolchain/linker support.

## Dependencies

Rust/Cargo for workspace tests and CLI; PowerPC cross tools and a matching Galaxy 1 toolchain for runtime proof; Ghidra or compatible PPC disassembler for hook analysis; Dolphin and user-supplied legal game files for runtime validation.

## Risks

Unknown AllReds provenance and license; uncertain original revision; no source for AllReds; engine singleton assumptions; Rust PPC target/ABI and linker compatibility unverified; local environment may lack required tools.

## Acceptance criteria

- Hashes and DOL section tables independently reproduce.
- DOL diff tool has synthetic tests and never writes inputs.
- Research documents identify source, confidence, and unresolved questions.
- Architecture and milestone plan are Rust-first and preserve narrow integration boundaries.
- No runtime hook or compatibility claim without verified revision, address, ABI, and tests.

## Testing strategy

Run Cargo unit tests over synthetic DOL fixtures and run comparison on local reference files if the toolchain is available. Runtime acceptance remains pending until Dolphin boot and gameplay tests are available.
