# Classic Controller patch research

The identified project is [Wii-Patches/Galaxy-Patch](https://github.com/Wii-Patches/Galaxy-Patch). Its README states that it supports SMG1 USA, Europe, Japan, and Korea and describes synthesizing KPAD Classic Controller state, redirecting movement/pointer/spin handling, and polling GameCube SI ports because SMG lacks a PAD library.

This project has not been downloaded or audited at a pinned revision in this workspace. License, exact hooks, hash/revision matching, mappings, and patch overlap must be verified before reuse or integration. It does not establish simultaneous four-controller support. Plan on shared source-level integration or conflict-aware patch generation and test motion-dependent stages.
